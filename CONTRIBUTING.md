# Contributing Guide

Thank you for contributing to **AI Secretary**!  
This guide explains how to set up your local environment, follow the branch flow, and open pull requests safely.

---

## 🧰 Local Setup

### Prerequisites
- Python 3.10+
- Node 18+
- Git
- VS Code (with the recommended extensions from `.vscode/extensions.json`)

### 1. Clone & Initialize
```bash
git clone https://github.com/<your-username>/ai-secretary.git
cd ai-secretary
